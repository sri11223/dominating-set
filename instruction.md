# Minimum dominating set

Implement `/root/dominating_set_submission/solver.py`. For every instance set it is invoked on, the program must find a dominating set whose size does not exceed the minimum dominating-set size of the graph, and write the exact answer artifact required by `/root/data/CONTRACT.md`.

The program may use the standard library and the numpy, scipy and sympy packages; the numerical libraries are restricted to a single thread. Instances provide only vertex counts and edge lists; labels carry no structural information. The development instances under `/root/data/` include small representatives of both graph families: a relabelled 3-dimensional hypercube and a small hub/leaf graph. The program must find a minimum dominating set for each of four further instances: two relabelled 15-dimensional hypercubes (32768 vertices, 245760 edges) and two hub/leaf graphs (30000 vertices, 40000 edges).

You have 18000 seconds to complete this task. Do not cheat by using online solutions or hints specific to this task.
